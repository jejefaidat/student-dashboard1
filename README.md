# Student Dashboard

A one-page student dashboard built while learning React, Next.js, and TypeScript.

## Features

- Student profile with name, matric number, and department
- Assignment overview showing total, pending, and completed assignments
- Course list with course codes and titles
- Responsive layout

## Built with

- Next.js
- React
- TypeScript
- Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```
